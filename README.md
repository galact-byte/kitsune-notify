# 稻荷神社 回复邮件提醒

[kitsune.ee](https://kitsune.ee/) 帖子被回复时发邮件。浏览器油猴脚本轮询提醒页，Google Apps Script 用你的 Gmail 发出去。需要钉住一个论坛标签页；关机期间下次打开会补发。

## 1. 部署发信端（Apps Script，只做一次）

1. 打开 https://script.google.com/ ，新建项目。
2. 清空默认 `Code.gs`，粘贴本仓库 `Code.gs` 全文。
3. 改 `TO_EMAIL`（收件邮箱）和 `TOKEN`（自己设的口令，稍后油猴面板填同一份）。
4. 函数下拉选 `sendTestEmail` → 运行。第一次要授权：选账号 →「高级」→「转至（不安全）」→ 允许发 Gmail。邮箱收到「部署测试」即权限 OK。
5. 「部署」→「新建部署」→ 类型选 **网络应用 / Web app**：
   - 执行身份：**我**
   - 谁可以访问：**任何人 / Anyone**
   - 复制以 `/exec` 结尾的 URL

改过 `Code.gs` 后要再「管理部署」→ 编辑 → **新版本**。

## 2. 装油猴脚本

装 [Tampermonkey](https://www.tampermonkey.net/)，新建脚本，粘贴 `kitsune-notify.user.js`。登录 kitsune.ee，点右下角朱红图标，填 `/exec` URL、TOKEN、收件邮箱，保存。

## 3. 验证

| 按钮 | 期望 |
|---|---|
| **发送测试邮件** | 能进邮箱就通了。若提示网关超时，先查收、不要立刻再点 |
| **立即检查** | 首次只做基线、不发信 |
| **清空去重** → 再 **立即检查** | 把当前真实回复发一封过来 |

连点「立即检查」会触发论坛 IP 拦截，等几分钟。读提醒页会清站内红点。
