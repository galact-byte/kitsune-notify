# 稻荷神社 回复邮件提醒

[kitsune.ee](https://kitsune.ee/) 帖子被回复时，发一封邮件到你的邮箱。

浏览器里的油猴脚本轮询论坛提醒页；Google Apps Script 用你的 Gmail 发信。密钥填在面板里，不写进代码。

需要浏览器开着、且钉住一个论坛标签页。关机期间不实时推，下次打开会补发。当前版本 **v1.5.3**。

## 1. 部署发信端（Apps Script，只做一次）

1. 打开 https://script.google.com/ ，新建项目。
2. 清空默认 `Code.gs`，粘贴本仓库 `Code.gs` 全文。
3. 改开头两个值：
   - `TO_EMAIL`：收件邮箱（不必是 Gmail）
   - `TOKEN`：自己设的随机口令，**必须和稍后油猴面板里填的完全一致**
4. 函数下拉选 `sendTestEmail` → 运行。第一次会要授权：选账号 →「高级」→「转至（不安全）」→ 允许发 Gmail。邮箱收到「部署测试」即权限 OK。
5. 「部署」→「新建部署」→ 类型选 **网络应用 / Web app**：
   - 执行身份：**我**
   - 谁可以访问：**任何人 / Anyone**
   - 部署后复制以 **`/exec` 结尾**的 URL

改过 `Code.gs` 后必须再「管理部署」→ 编辑 → **新版本**，旧 `/exec` 不会自动吃到新代码。

## 2. 装油猴脚本

1. 装 [Tampermonkey](https://www.tampermonkey.net/)，新建脚本，粘贴本仓库 `kitsune-notify.user.js`，保存。
2. 登录 kitsune.ee，点页面**右下角朱红圆形图标**，填 `/exec` URL、TOKEN、收件邮箱，保存。可选「也被 @ 时发邮件」（默认关）。

## 3. 验证

点图标打开面板，按这个顺序：

| 按钮 | 期望 |
|---|---|
| **发送测试邮件** | 提示已发送，或「网关超时、多半已发出」。**先查收，不要立刻再点**（冷启动 408 时信往往已经出去了） |
| **立即检查** | 首次只做基线、不发信，正常 |
| **清空去重** → 再 **立即检查** | 会把当前真实回复发一封过来 |

测试邮件能进邮箱 = 整条链路通了。

## 注意

- URL 必须 `/exec` 结尾；两边 TOKEN 必须一致；「谁可以访问」必须是任何人。
- 连点「立即检查」会触发 Discuz IP 拦截，等 5–10 分钟自解。脚本已有 30 秒节流。
- 后台读提醒页会清该类型站内红点（换来邮件）。离线期间超过 30 条的最旧部分可能漏接。
- 改轮询间隔：脚本里 `POLL_INTERVAL_MIN`（默认 5 分钟）。
